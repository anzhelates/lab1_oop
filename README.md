# Лабораторна робота 1

## Завдання

Створити консольний додаток, що відповідає наступним вимогам:
1.	Використовувати можливості ООП: класи, успадкування, поліморфізм, інкапсуляція.
2.	Кожен клас повинен мати змістовну назву та інформативне наповнення.
3.	Успадкування повинно застосовуватися лише тоді, коли це має сенс.
4.	При кодуванні використати оформлення коду відповідно до Java Code Convention. https://www.oracle.com/docs/tech/java/codeconventions.pdf
5.	Класи повинні бути коректно розподілені по Java-пакетах.
6.	Робота з консоллю або консольне меню повинно бути мінімальним.
7.	Для збереження параметрів ініціалізації можна використовувати файли.
8.	Весь код повинен бути покритий Unit-тестами. Використовувати JUnit 4 або 5, Mockito.
9.	Код повинен бути розміщений на віддаленому репозиторії. Історія змін повинна мати логічні commit-повідомлення, репозиторій має мати правильно налаштований gitignore файл.

**Варіант 9. Авіакомпанія.**
Визначити ієрархію літаків. Створити авіакомпанію. Порахувати загальну
місткість і вантажопідйомність. Провести сортування літаків компанії за
дальністю польоту. Знайти літак у компанії, що відповідає заданому діапазону
параметрів споживання палива.

## Реалізація

- **Ієрархія літаків:**
  - `Aircraft` (абстрактний): реєстрація, виробник, модель, дальність, витрата
    палива, `canFly`.
  - `PassengerAircraft`: додає кількість пасажирських місць.
  - `CargoAircraft`: додає вантажопідйомність (має бути додатною).
- **`Airline`:** список літаків з унікальними реєстраційними номерами.
  - загальна пасажиромісткість і вантажопідйомність;
  - сортування за дальністю;
  - пошук за діапазоном споживання палива (кг/год);
  - додатково: пошук літаків, що долітають на задану відстань.
- **Дані авіапарку** з текстового файлу в ресурсах:
  - `AircraftLoader` читає файл, при помилці вказує номер рядка;
  - `AircraftFactory` створює літак за типом рядка (`PASSENGER` / `CARGO`).
- **`Main`** завантажує авіапарк і друкує звіт.

### Формат файлу даних

`src/main/resources/aircraft_data.txt`, один літак на рядок, поля через `;`:

```
PASSENGER;реєстрація;виробник;модель;дальність_км;паливо_кг_год;місць
CARGO;реєстрація;виробник;модель;дальність_км;паливо_кг_год;вантаж_кг
```

## Тести

JUnit 5 та Mockito.

- `PassengerAircraftTest` - Дані літака, `canFly`, `toString`, валідація;
- `CargoAircraftTest` - Дані літака, валідація вантажопідйомності;
- `AircraftFactoryTest` - Створення літаків з полів, помилки формату;
- `AircraftLoaderTest` - Читання файлу, порожні рядки, номер рядка в помилці;
- `AirlineTest` - Підрахунки, сортування, пошук, дублікати (Mockito).

### Покриття (JaCoCo)

Звіт: `build/reports/jacoco/test/html/index.html`

Покриття: 100% без `Main` (виключено зі звіту, лише виводить звіт у консоль);
79% разом із `Main`.
