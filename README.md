# Лабораторна робота 1

## Завдання:

Створити консольний додаток, що відповідає наступним вимогам:
1.	Використовувати можливості ООП: класи, успадкування, поліморфізм, інкапсуляція.
2.	Кожен клас повинен мати змістовну назву та інформативне наповнення.
3.	Успадкування повинно застосовуватися лише тоді, коли це має сенс.
4.	При кодуванні використати оформлення коду відповідно до Java Code Convention. https://www.oracle.com/docs/tech/java/codeconventions.pdf
5.	Класи повинні бути коректно розподілені по Java-пакетах.
6.	Робота з консоллю або консольне меню повинно бути мінімальним.
7.	Для збереження параметрів ініціалізації можна використовувати файли.
8.	Весь код повинен бути покритий Unit-тестами. Використовувати JUnit 4 або 5, Mockito.
9.	Код повинен бути розміщений на віддаленому репозиторії. Історія змін повинна мати логічні commit-повідомлення, репозиторій має мати правильно налаштований gitignore файл.

**Варіант 9. Авіакомпанія.**
Визначити ієрархію літаків. Створити авіакомпанію. Порахувати загальну
місткість і вантажопідйомність. Провести сортування літаків компанії за
дальністю польоту. Знайти літак у компанії, що відповідає заданому діапазону
параметрів споживання палива.

## Що зроблено

- **Ієрархія літаків:** абстрактний `Aircraft` та два підкласи,
  `PassengerAircraft` і `CargoAircraft`.
  - `Aircraft` містить спільні дані (реєстрація, виробник, модель, дальність,
    витрата палива, вантажопідйомність) і перевірку `canFly`. Реєстрація
    ідентифікує конкретний борт, а виробник з моделлю описують тип літака.
  - `PassengerAircraft` додає кількість пасажирських місць.
  - `CargoAircraft` перевозить вантаж, його вантажопідйомність
    має бути додатною.
- **Авіакомпанія** `Airline` зі списком літаків; реєстраційні номери
  унікальні.
- **Підрахунок** загальної пасажиромісткості та вантажопідйомності парку.
- **Сортування** літаків за дальністю польоту.
- **Пошук** літаків за діапазоном споживання палива (кг/год).
- **Додатково:** пошук літаків, що можуть виконати рейс на задану відстань.
- **Дані парку** завантажуються з текстового файлу в ресурсах:
  - `AircraftLoader` читає файл рядок за рядком і при помилці вказує номер
    рядка;
  - `AircraftFactory` за типом рядка (`PASSENGER` / `CARGO`) створює потрібний
    літак.
- **`Main`** завантажує парк, створює авіакомпанію і друкує звіт у консоль.
- **Тести:** JUnit 5 + Mockito, покриття вимірюється через JaCoCo.

### Формат файлу даних

Файл `src/main/resources/aircraft_data.txt`, один літак на рядок, поля через `;`:

```
PASSENGER;реєстрація;виробник;модель;дальність_км;паливо_кг_год;місць;вантаж_кг
CARGO;реєстрація;виробник;модель;дальність_км;паливо_кг_год;вантаж_кг
```

## Запуск

Java 21.

Запуск програми:
```
.\gradlew run
```
Тест та звіт покриття:
```
.\gradlew test
```

## Тести

Використано **JUnit 5** та **Mockito**.

| Клас | Що перевіряє |
|---|---|
| `PassengerAircraftTest` | Дані літака, `canFly`, `toString`, валідація аргументів |
| `CargoAircraftTest` | Вантажний літак: нуль пасажирів, валідація вантажу |
| `AircraftFactoryTest` | Створення літаків з полів, помилки формату |
| `AircraftLoaderTest` | Читання парку, пропуск порожніх рядків, номер рядка в помилці |
| `AirlineTest` | Підрахунки, сортування, пошук, дублікати (Mockito) |
| `MainTest` | Повний вивід програми |
